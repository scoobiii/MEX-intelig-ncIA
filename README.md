# Run and deploy your AI MEX Studio app

This contains everything you need to run your app locally.

View your MEX AI Dashboard: https://scoobiii.github.io/MEX-intelig-ncIA

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
2. git clone https://github.com/scoobiii/MEX-intelig-ncIA.git
3. cd MEX-intelig-ncIA
   `npm install`
4. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
5. Run the app:
   `npm run dev`
